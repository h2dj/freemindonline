# FreeMind Online

브라우저에서 바로 쓰는 마인드맵 편집기입니다. [FreeMind](https://freemind.sourceforge.io/wiki/index.php/Main_Page) 데스크톱 프로그램의 사용감(중앙 주제에서 좌우로 뻗는 트리 구조, 키보드 중심 편집, `.mm` 파일 포맷)을 웹으로 옮겨 왔습니다.

빌드 도구나 서버 없이 정적 파일만으로 동작하는 순수 HTML/CSS/JavaScript(ES 모듈) 프로젝트입니다.

## 사용해 보기

로컬에서 정적 파일 서버로 열면 됩니다 (ES 모듈이라 `file://`로 직접 열면 브라우저가 막을 수 있습니다):

```bash
npx serve .
# 또는
python3 -m http.server 8000
```

이후 브라우저에서 `http://localhost:8000` 접속.

## 배포

`main` 브랜치에 푸시되면 `.github/workflows/deploy-pages.yml` 워크플로가 자동으로 GitHub Pages에 배포합니다. 저장소 Settings → Pages에서 Source를 "GitHub Actions"로 한 번 설정해 두면, 이후로는 `main`에 머지될 때마다 자동으로 최신 버전이 배포됩니다.

## 주요 기능

- 중심 주제를 기준으로 좌/우 양쪽으로 뻗는 자동 트리 레이아웃
- 노드 추가/편집/삭제, 접기·펼치기
- 모바일/터치 화면에서는 새 노드를 추가할 때마다(하위·형제·새 상위 노드 모두) 화면이 자동으로 그 노드를 중심에 맞춰 이동함 — 화면이 좁아 새로 만든 노드가 보이지 않는 일을 방지 (화면이 넓은 데스크톱에서는 적용되지 않음)
- 드래그로 캔버스 이동(팬), 마우스 휠로 확대·축소
- 노드를 드래그해서 다른 노드의 하위로 재배치
- 노드 색상 지정
- 구름으로 노드(와 하위 트리 전체) 강조 표시, 구름 색상 변경
- 노드에 하이퍼링크(URL·메일주소) 추가 — 링크 배지를 클릭하면 새 탭에서 열림
- 노드에 아이콘 여러 개 추가(선택한 팔레트에서), 마지막 아이콘/전체 아이콘 제거
- 노드에 이미지 업로드해서 삽입 — 텍스트 위에 썸네일로 표시, 자동으로 축소·재인코딩해 저장
- 임의의 두 노드를 잇는 그래픽 링크(화살표) 추가 — 부모·자식 관계와 무관하게 연결, 색상·화살표 스타일 변경, 삭제
- 노드에 체크박스 추가 — 체크박스가 있는 노드가 하나라도 있으면 왼쪽에 **체크리스트 패널**이 자동으로 나타남. 노션(Notion) 스타일 마크다운 작업 목록으로 클립보드에 복사하거나, CSV 파일로 내보내 엑셀·구글 시트에서 열기 가능
- 노드에 새 상위 노드를 끼워 넣기 (`Shift+Insert`) — 선택한 노드를 감싸는 새 부모 노드를 만듦 (승격의 반대 동작)
- 선택한 노드를 새 탭의 중심 주제로 열기 — 원본은 그대로 두고, 그 노드와 하위 트리 전체를 별도 탭으로 분리해서 봄
- 실행 취소 / 다시 실행 (Ctrl+Z / Ctrl+Shift+Z)
- 여러 개의 마인드맵을 탭으로 동시에 열어두고 전환 — 탭마다 독립된 실행 취소 기록과 화면(팬/줌) 상태를 유지
- 브라우저 `localStorage`에 자동 저장 — 새로고침해도 열려 있던 탭 구성까지 그대로 유지
- JSON 파일로 저장/열기 (이 앱 전용 포맷, 모든 정보 보존)
- FreeMind 네이티브 `.mm` 파일로 내보내기/가져오기 (데스크톱 FreeMind와 상호 호환)
- 마크다운(`.md`) 파일로 내보내기/가져오기 (중첩 글머리 기호 목록 — 체크박스는 GFM 작업 목록으로, 링크는 `[텍스트](URL)`로)
- PNG 이미지로 내보내기 (현재 화면이 아니라 맵 전체를, 구름·아이콘·링크·그래픽 링크까지 포함해 2배 해상도로 저장)
- 저장/내보내기 파일 이름은 항상 `mindmap_중심주제_저장한날짜.확장자` 형식(예: `mindmap_내_프로젝트_계획_2026-08-18.json`) — 파일명만 보고도 어떤 맵인지, 언제 저장했는지 구분 가능
- 📤 공유: 지원하는 브라우저(주로 모바일)에서는 OS 공유 시트를 띄워 JSON 파일을 메일 앱 등에 바로 첨부해서 보낼 수 있음. 지원하지 않는 브라우저에서는 파일을 내려받은 뒤 첨부하라는 안내와 함께 메일 작성 화면을 엽니다
- 인쇄 (현재 화면이 아니라 맵 전체를 새 탭에 이미지로 띄운 뒤 인쇄 대화상자 실행)
- 기초 설정: 글자 크기, 노드 기본 색상, 중심 주제(강조) 색상, 노드 선 스타일(테두리 박스/테두리 없는 박스/밑줄만), 키보드 종류(Windows/Mac) — 브라우저에 저장되어 다음 방문에도 유지됨

## 키보드 단축키

| 동작 | 단축키 |
| --- | --- |
| 하위 노드 추가 | `Insert` (⚙ 기초 설정에서 키보드 종류를 Mac으로 두면 `Tab`도 가능 — Mac 키보드에는 Insert 키가 없어서) |
| 새 상위 노드 끼워 넣기 | `Shift+Insert` |
| 형제 노드 추가 | `Enter` |
| 선택한 노드 편집 | `F2` 또는 더블클릭 |
| 편집 완료 | `Enter` (편집 중) |
| 편집 취소 | `Esc` |
| 노드 삭제 | `Delete` / `Backspace` |
| 접기/펼치기 | `Space` |
| 노드 간 이동(선택) | 방향키 |
| 형제 노드 순서 변경 | `Ctrl+↑` / `Ctrl+↓` |
| 상위/하위 레벨로 이동(승격·강등) | `Ctrl+←` / `Ctrl+→` |
| 실행 취소 / 다시 실행 | `Ctrl+Z` / `Ctrl+Shift+Z` |
| JSON으로 저장 | `Ctrl+S` |
| 인쇄 | `Ctrl+P` |
| 하이퍼링크 추가/변경 | `Ctrl+K` |
| 구름 켜기/끄기 | `Ctrl+Shift+J` |

`Ctrl+←`/`Ctrl+→` 중 어느 쪽이 승격(상위 레벨로)인지 강등(하위 레벨로)인지는 노드가 루트의 왼쪽/오른쪽 중 어느 가지에 있는지에 따라 달라집니다 — 루트에서 멀어지는 방향이 항상 강등입니다. 중심 주제 바로 아래(최상위) 노드는 더 승격할 곳이 없으므로, 그 자리에서는 대신 루트 반대편 가지로 통찀로 이동합니다.

위/아래 방향키로 노드 사이를 이동할 때는 같은 편(좌/우) 안에서 트리를 위에서 아래로 읽는 순서(부모 → 그 하위 트리 전체 → 다음 형제)를 그대로 따라가므로, 한 노드의 형제 목록 끝에 도달하면 자연스럽게 다음 가지로 이어서 이동합니다. 이 순서는 화면 좌표가 아니라 트리 구조 자체를 따르기 때문에 반대편(좌/우)으로 튀거나 특정 노드에 도달하지 못하는 일이 없습니다.

마우스 오른쪽 클릭으로 컨텍스트 메뉴를 열 수도 있습니다.

## 툴바 구성

상단 툴바는 항상 한 줄을 유지하도록 왼쪽(브랜드 · ☰ 메뉴 · 노드 추가/삭제/실행취소— 자주 쓰는 기능)과 오른쪽(확대·축소 · 패널 보이기/숨기기 · 색상)으로 나뉘어 있습니다. 새로 만들기·열기·저장·`.mm`/`.md`/PNG 내보내기·가져오기·인쇄·설정처럼 자주 쓰지 않는 기능은 왼쪽의 **☰ 메뉴** 버튼을 누르면 나오는 드롭다운에 모아뒀습니다. 화면이 그래도 좁으면(모바일 등) 툴바 자체가 가로로 스크롤되어, 어떤 화면 크기에서도 두 줄로 늘어나지 않습니다.

오른쪽 그룹의 **🧩**/**✅** 버튼으로 아이콘 사이드바와 체크리스트 패널을 각각 켜고 끌 수 있습니다 — 켜져 있으면 파란 배경으로 표시됩니다. 체크리스트 쪽은 문서에 체크박스가 아직 없어도 항상 눌러서 열 수 있는데, 패널 자체에 체크박스를 새로 추가하는 버튼이 있기 때문입니다(아래 "체크리스트" 참고). 아이콘 사이드바의 기본 표시 여부(다음 방문에도 유지되는 값)는 **⚙ 설정**에서 바꿀 수 있습니다.

캔버스 왼쪽에는 **아이콘 사이드바**가 있어 아이콘 팔레트 전체를 항상 볼 수 있습니다. 맨 위에는 선택한 노드의 마지막 아이콘/전체 아이콘을 지우는 두 버튼(⌫ / 🗑)이 가로선으로 구분되어 있고, 그 아래로 팔레트가 이어집니다.

## 구름 · 하이퍼링크 · 아이콘 · 이미지 · 체크박스 · 그래픽 링크

노드를 우클릭(또는 모바일에서 롱프레스)하면 나오는 컨텍스트 메뉴에서 다음 기능을 쓸 수 있습니다.

- **☁ 구름**: 노드와 그 하위 트리 전체를 감싸는 강조 영역을 추가합니다. 다시 클릭하면 색상이 차례로 바뀌고, 제거도 가능합니다. `Ctrl+Shift+J`로 켜고 끌 수 있습니다.
- **🔗 하이퍼링크**: URL이나 `mailto:` 주소를 입력해 노드에 링크를 겁니다. 링크가 있는 노드에는 작은 🔗 배지가 표시되며, 배지를 클릭하면 새 탭에서 열립니다.
- **😀 아이콘**: 노드 텍스트 바로 앞, 같은 줄에 작은 아이콘을 여러 개 붙일 수 있습니다(37종 팔레트에서 선택 — 체크·X·물음표·별표, 서로 다른 색 배경에 흰 숫자로 표시되는 1~9번 배지, 사람 모양 몇 종류, 폭탄·노트·마법봉·돋보기·모래시계·무지개 깃발 등). 마지막 아이콘만 제거하거나 전체를 지울 수도 있습니다(컨텍스트 메뉴, 또는 아이콘 사이드바 맨 위의 ⌫/🗑 버튼). 컨텍스트 메뉴 대신 화면 왼쪽의 **아이콘 사이드바**(팔레트 전체가 항상 보이는 좁은 세로 목록)에서 바로 클릭해서 추가할 수도 있습니다 — 노드를 선택한 상태에서 아이콘 하나를 클릭하면 즉시 그 노드에 붙습니다.
- **🖼 이미지**: 노드에 이미지를 하나 업로드해서 텍스트 위에 작은 썸네일로 붙일 수 있습니다("이미지 추가" 선택 → 파일 선택). 이미 이미지가 있는 노드는 "이미지 바꾸기"로 교체하거나 "이미지 제거"로 뗄 수 있습니다. 화면에는 최대 200×140px로, 원본 비율을 유지한 채 축소해서 보여줍니다. 문서 용량을 아끼려고 업로드한 원본도 (화면 표시보다 훨씬 여유 있게) 최대 800px로 한 번 줄여서 저장하며, 그래도 너무 크면 추가를 거부합니다. PNG는 투명도를 살리려고 PNG로, 그 외 형식은 JPEG로 다시 인코딩합니다.
- **☑ 체크박스**: 노드에 체크박스를 붙이거나 뗍니다. 체크박스는 노드 텍스트 맨 앞에 표시되고, 클릭할 때마다 완료/미완료가 바뀝니다. 자세한 내용은 아래 "체크리스트" 항목 참고.
- **↗ 그래픽 링크**: 부모·자식 관계와 무관하게 임의의 두 노드를 화살표로 연결합니다. 시작할 노드에서 "그래픽 링크 시작"을 선택한 뒤, 연결할 노드에서 "여기로 그래픽 링크 연결"을 선택하면 완성됩니다 (`Esc`로 취소 가능). 화살표 자체를 우클릭하면 색상·화살표 스타일 변경, 삭제를 할 수 있고, 클릭으로 선택한 뒤 `Delete`로도 지울 수 있습니다.

이 여섯 가지 모두 JSON 저장/불러오기와 undo/redo에 포함됩니다. PNG 내보내기·인쇄에도 이미지가 그대로 함께 찍힙니다. 구름·하이퍼링크·아이콘·그래픽 링크는 FreeMind `.mm` 포맷으로 내보내고 가져올 때도 (구름은 `<cloud>`, 링크는 `LINK` 속성, 그래픽 링크는 `<arrowlink>`로) 함께 보존됩니다. 체크박스와 이미지는 `.mm`에는 비표준 속성/요소로 저장되어 이 앱에서 다시 열면 그대로 복원되지만, 데스크톱 FreeMind에는 그런 개념 자체가 없어(이미지는 외부 파일 참조 방식만 지원) 다른 값으로 표시되지는 않습니다. 아이콘은 데스크톱 FreeMind의 고정 아이콘 목록 대신 이모지를 사용하므로, 실제 FreeMind에서 만든 `.mm` 파일을 가져올 때는 흔히 쓰이는 아이콘 이름 일부만 이모지로 매핑하고 나머지는 원래 이름 그대로 표시합니다.

## 체크리스트

노드에 체크박스를 하나라도 추가하면(컨텍스트 메뉴의 "☑ 체크박스 추가", 또는 아래 패널 버튼) 캔버스 왼쪽에 **체크리스트 패널**이 자동으로 나타납니다. 툴바의 **✅** 버튼으로 언제든 직접 켜고 끌 수 있으며 — 체크박스가 아직 하나도 없어도 켤 수 있습니다 — 이렇게 수동으로 선택한 상태는 다시 누를 때까지 유지됩니다.

패널 헤더의 **📋** 버튼을 누르면 현재 체크리스트 전체가 노션(Notion) 스타일 마크다운 작업 목록(`- [ ] 할 일` / `- [x] 완료한 일`, 한 줄에 항목 하나씩)으로 클립보드에 복사됩니다. 노션이나 다른 마크다운 인식 편집기에 그대로 붙여넣으면 각 줄이 개별 체크리스트(할 일) 블록으로 바뀝니다. 체크박스가 하나도 없으면 버튼이 비활성화됩니다.

바로 왼쪽의 **🧭** 버튼은 복사(와 아래 CSV 내보내기)에 상위 노드 경로를 포함할지 정하는 토글입니다. 켜져 있으면(기본값) 각 항목 오른쪽에 그 노드의 상위 노드 경로가 괄호로 붙어서(예: `- [ ] Leaf (중심 주제 › Branch)`) 트리에서 흩어져 있던 항목들을 평평한 목록으로 복사해도 어디서 온 항목인지 알 수 있습니다 — 중심 주제 자신에 붙은 체크박스처럼 상위 노드가 없는 항목은 괄호 없이 표시됩니다. 꺼두면 괄호 없이 순수한 할 일 텍스트만 복사됩니다.

**📋** 옆의 **📥** 버튼은 같은 체크리스트를 CSV 파일로 내보냅니다(`완료`/`할 일`/🧭가 켜져 있으면 `상위 노드 경로` 열, `완료`는 엑셀·구글 시트가 참/거짓으로 알아보는 `TRUE`/`FALSE` 값). 파일 이름은 다른 내보내기와 같은 `mindmap_중심주제_날짜.csv` 형식이고, 엑셀에서 한글이 깨지지 않도록 UTF-8 BOM을 붙여 저장합니다. 체크박스가 하나도 없으면 버튼이 비활성화됩니다.

패널 맨 위에는 체크박스를 추가하는 두 가지 방법이 있습니다.

- **➕ 체크박스 추가**: 캔버스에서 선택한 노드 하나에 체크박스를 추가합니다(이미 체크박스가 있으면 비활성화). 아직 체크박스가 하나도 없는 문서에서 첫 체크박스를 만들 때도 이 버튼으로 패널을 먼저 연 뒤 바로 쓸 수 있습니다.
- **📌 연속 추가**: 누르면 켜지는 토글입니다. 켜져 있는 동안에는 캔버스에서(또는 방향키로) 새 노드를 선택할 때마다 그 노드에 체크박스가 자동으로 붙습니다 — 여러 노드를 빠르게 체크리스트로 만들 때 노드를 하나씩 클릭만 하면 됩니다. 캔버스에서 이미 체크박스가 있는 노드를 다시 클릭(또는 탭)하면 체크박스가 제거됩니다 — 잘못 찍었거나 더 이상 필요 없는 항목을 바로 되돌릴 수 있습니다. 다만 방향키로 노드 사이를 이동할 때는 지나치는 노드의 체크박스가 지워지지 않고 그대로 유지됩니다(둘러보다 실수로 지우는 일을 막기 위함). 다시 눌러서 끄거나, 다른 탭으로 전환하면 자동으로 꺼집니다.

패널 목록 부분은 다음과 같이 동작합니다.

- 문서 안의 모든 체크박스 노드가 (접혀 있는 가지 안에 있어도) 완료/전체 개수와 함께 나열됩니다.
- 목록의 체크박스를 클릭하면 완료 상태가 바뀌고, 노드 텍스트를 클릭하면 캔버스에서 그 노드가 선택됩니다.
- 항목을 클릭해 선택하면 그 아래에 중심 주제부터 이어지는 **상위 노드 경로**가 함께 표시되어, 트리의 다른 부분이 접혀 있거나 화면 밖에 있어도 그 항목이 어디에 있는지 바로 알 수 있습니다.
- 캔버스에서도 노드 앞의 체크박스(☐/☑)를 직접 클릭해 완료 상태를 바꿀 수 있습니다.

## 새 탭에서 중심 주제로 열기

노드를 우클릭한 뒤 "🗂 새 탭에서 중심 주제로 열기"를 선택하면, 그 노드와 하위 트리 전체를 복사해 새 탭으로 열고 그 노드를 새 탭의 중심 주제로 삼습니다. 원본 탭은 전혀 바뀌지 않으므로, 큰 맵의 한 가지에만 집중해서 보거나 편집하고 싶을 때 유용합니다. (부모·자식 관계를 벗어난 그래픽 링크는 두 끝이 모두 복사된 하위 트리 안에 있을 때만 함께 옮겨집니다.)

## 공유

☰ 메뉴의 **📤 공유** 버튼은 현재 맵을 이 앱 전용 JSON 포맷(모든 정보를 보존하는 파일)으로 다른 사람에게 바로 보낼 수 있게 해줍니다.

- 파일 공유를 지원하는 브라우저(대부분의 모바일 Safari·Chrome)에서는 OS의 공유 시트가 뜹니다. 여기서 메일 앱을 고르면 JSON 파일이 곧바로 첨부된 채로 새 메일이 열리고, 카카오톡 등 다른 앱으로 보낼 수도 있습니다.
- 파일 공유를 지원하지 않는 브라우저(대부분의 데스크톱 Chrome·Firefox — 웹 표준상 `mailto:` 링크는 파일 첨부를 지원하지 않습니다)에서는 대신 JSON 파일을 내려받은 뒤, 제목이 채워진 메일 작성 화면을 열어줍니다. 방금 받은 파일을 그 메일에 직접 첨부해서 보내면 됩니다.

두 경우 모두 파일 이름은 저장/내보내기와 같은 `mindmap_중심주제_날짜.json` 규칙을 따릅니다.

## 인쇄 · 기초 설정

- **🖨 인쇄** (`Ctrl+P`): 현재 화면(팬/줌 상태)이 아니라 맵 전체를 대상으로, PNG 내보내기와 동일한 방식으로 새 탭에 이미지를 띄운 뒤 그 탭에서 브라우저 인쇄 대화상자를 엽니다. 팝업이 차단되어 있으면 안내 메시지가 뜨니 팝업 차단을 해제해 주세요.
- **⚙ 설정**: 툴바 오른쪽 끝의 설정 버튼을 누르면 다음을 바꿀 수 있는 패널이 열립니다.
  - **글자 크기**: 슬라이더로 11~20px 사이에서 조정. 드래그하는 동안 바로 미리보기되고, 손을 떼면 저장됩니다.
  - **노드 기본 색상**: 개별 노드에 직접 색을 지정하지 않았을 때 쓰이는 기본 배경색.
  - **중심 주제(강조) 색상**: 중심 주제 노드와 선택 표시 등 앱 전체의 강조색.
  - **아이콘 사이드바 기본으로 보이기**: 앱을 열었을 때 아이콘 사이드바가 보이는 상태로 시작할지 정합니다. 툴바의 🧩 버튼으로 켜고 끌 때도 같은 값이 즉시 갱신되어, 다음 방문에도 마지막으로 선택한 상태가 유지됩니다.
  - 이 설정들은 현재 열려 있는 맵 문서가 아니라 브라우저(이 기기의 `localStorage`)에 저장되는 앱 전체 환경설정이라, 새 맵을 만들거나 다른 파일을 열어도 그대로 유지됩니다. "기본값으로 되돌리기"로 언제든 초기화할 수 있습니다. PNG 내보내기와 인쇄에도 그대로 반영됩니다(단, 아이콘 사이드바 표시 여부는 화면 UI에만 적용됩니다).

## 여러 맵(탭)

메뉴 바로 아래 **탭 바**에서 여러 개의 마인드맵을 동시에 열어두고 전환할 수 있습니다.

- **+ 버튼**으로 새 빈 마인드맵 탭을 추가합니다. 탭 이름은 각 맵의 중심 주제 텍스트를 그대로 따라갑니다.
- 탭을 클릭하면 전환되고, 탭의 **×** 버튼으로 닫을 수 있습니다.
- 각 탭은 실행 취소/다시 실행 기록, 팬(이동) 위치, 확대/축소 배율을 독립적으로 유지합니다 — 다른 탭에서 무엇을 했든 서로 영향을 주지 않습니다.
- 마지막 남은 탭을 닫으려 하면 확인 후 그 탭을 새 빈 마인드맵으로 초기화합니다 (탭이 0개인 상태는 없음).
- 열려 있는 탭 구성(모든 탭의 내용, 활성 탭, 각 탭의 화면 상태)은 `localStorage`에 자동 저장되어 새로고침해도 그대로 복원됩니다. 이 기능이 추가되기 전에 저장된 단일 문서도 첫 실행 시 자동으로 탭 하나로 옮겨집니다.

```
js/model.js          마인드맵 데이터 모델과 변경 함수
js/layout.js         트리 레이아웃 계산
js/icons.js          아이콘 토큰(이모지/숫자 배지) 공용 렌더링 규칙

js/render.js         상태 → DOM/SVG 렌더링
js/interactions.js   마우스/키보드 이벤트 처리
js/io.js             저장/불러오기(여러 탭 저장 포함), JSON, FreeMind .mm 변환, 마크다운 변환, PNG 내보내기, 인쇄
js/settings.js        앱 전체 환경설정(글자 크기 · 기본 색상) 로드/저장/적용
js/undo.js           실행 취소/다시 실행 히스토리
js/main.js           앱 초기화 및 위 모듈들을 연결
```

## 알려진 제한사항 / 다음 단계

- 서식 있는 텍스트(richcontent), 로컬 파일 첨부(파일 선택형 하이퍼링크)는 아직 미지원 — 하이퍼링크는 URL/메일주소 입력 방식만 지원
- 아이콘은 데스크톱 FreeMind의 고정 35종 대신 이모지 팔레트를 사용
- 그래픽 링크의 곡선 경로를 드래그로 직접 조정하는 기능은 아직 없음 (자동 배치된 곡선만 지원)
- 마크다운 내보내기/가져오기는 텍스트 계층 구조·체크박스·하이퍼링크만 보존함 — 색상·구름·아이콘·이미지·그래픽 링크가 필요하면 JSON이나 `.mm`을 사용
- 협업/실시간 동기화 없음 (로컬 저장 및 파일 내보내기만 지원)
